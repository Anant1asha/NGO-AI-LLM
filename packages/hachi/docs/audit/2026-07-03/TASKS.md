## How to use this board (read before picking a task)

1. Read this file top to bottom. Skip any task marked `In Progress` or `Done`.
2. Pick the highest-priority `Todo` task whose `Dependencies` are all `Done` and whose files don't
   overlap a task currently `In Progress` (see **Concurrency notes** below).
3. Flip its status to `In Progress` **before** you start (edit this file, commit-worthy change).
4. Work it per CLAUDE.md: failing regression test first (for bugs) → minimal fix → `docs/bug-bank.md`
   entry → run the relevant gate. Use the `regression-guard` subagent for bug-fix tasks.
5. Flip status to `Done` (or `Blocked` + why) and fill in `Validation status` with the _actual_ command
   output, not "should work."
6. If you discover new work, append a new task row — never silently fold it into an existing one.
