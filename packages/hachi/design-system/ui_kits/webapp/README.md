# Hachi web app UI kit

A high-fidelity recreation of the Hachi web app (React / TanStack Start). Warm cream canvas,
hairline-bordered run cards, the signature leash prompt, and an always-visible budget.

## Files
- `index.html` — interactive entry. Renders the full app shell and wires the demo flow.
- `Sidebar.jsx` — left nav rail (`window.Sidebar`): wordmark, nav (Runs / The pack / The kennel /
  Terminal / Settings), and the budget summary panel.
- `Workspace.jsx` — main Runs view (`window.Workspace`): top bar, run-card grid, and the
  interactive leash-prompt → toast flow.
- `icons.jsx` — the Lucide icon set (`window.Icon`), stroke 1.75, currentColor.

## Interaction
Click **New run** → the leash prompt appears → **Allow once / Always allow** starts a working run
and shows a toast; **Deny** dismisses calmly. Clicking the scrim also denies.

## Composes
`HachiMark`, `RunCard`, `LeashPrompt`, `Button`, `Toast` from the design-system bundle —
no primitives are re-implemented here.

> The bundle (`_ds_bundle.js`) is generated by the compiler; it must exist for this page to render.
