The Hachi mascot, inline as SVG so it needs no asset path. Use for brand presence in headers, the leash prompt, empty states.

```jsx
<HachiMark size={48} />
<HachiMark size={20} variant="knockout" style={{ color: "var(--hachi-ink)" }} />
```

`two-tone` is the full mascot — **never recolour it**. `knockout` is a one-colour silhouette in `currentColor`, safe down to 16px, for monochrome contexts.
