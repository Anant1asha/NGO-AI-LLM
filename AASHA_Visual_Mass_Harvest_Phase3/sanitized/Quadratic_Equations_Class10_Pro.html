Exercise 4.1 — Standard Form & Modeling

मानक रूप एवं वास्तविक जीवन की परिस्थितियाँ
Class 10 NCERT 4.1
📌 Definition & Canonical Standard Form
An equation of the form ax² + bx + c = 0 is called a quadratic equation in variable x, where a, b, c ∈ ℝ and a ≠ 0.
Why a ≠ 0? If a = 0, the term with degree 2 disappears, and the equation collapses into a linear equation bx + c = 0.
ax² + bx + c = 0   (a ≠ 0)
Degree of polynomial = 2. Always simplify all brackets and gather terms before deciding degree!
NCERT Ex 4.1 • Check Identity Algebraic Cancellation Check
Check whether (x - 2)(x + 1) = (x - 1)(x + 3) is a quadratic equation.
Step 1: Expand Left Hand Side (LHS)
(x - 2)(x + 1) = x² + x - 2x - 2 = x² - x - 2
Step 2: Expand Right Hand Side (RHS)
(x - 1)(x + 3) = x² + 3x - x - 3 = x² + 2x - 3
Step 3: Equate LHS = RHS and Bring to One Side
x² - x - 2 = x² + 2x - 3
Subtract x² from both sides: x² cancels out!
-x - 2x - 2 + 3 = 0 ⟹ -3x + 1 = 0 (or 3x - 1 = 0).
Since the highest power of x is 1, this is a linear equation, NOT a quadratic equation!
NCERT Ex 4.1 Q2 (i) • Modeling Word Problem Formulation
The area of a rectangular plot is 528 m². The length of the plot (in metres) is one more than twice its breadth. Formulate the quadratic equation to find the length and breadth.
Step 1: Assign the Variable to the Unknown
Let the breadth of the plot be x metres.
Step 2: Express Length in Terms of Breadth
Length is 1 more than twice breadth: Length = 2x + 1 metres.
Step 3: Relate to Given Area
Area = Length × Breadth = (2x + 1)x = 2x² + x
Given Area = 528 m² ⟹ 2x² + x = 528
Standard Form: 2x² + x - 528 = 0

Exercise 4.2 — Solution by Factorisation

गुणनखंड विधि द्वारा द्विघात समीकरण का हल
Class 10 NCERT 4.2
⚡ The Splitting of Middle Term Technique
To solve ax² + bx + c = 0, we find two numbers p and q such that:
1. Sum: p + q = b
2. Product: p · q = a · c
Once grouped into linear factors (rx + s)(tx + u) = 0, we use the Zero Product Rule: either factor must equal 0!
NCERT Ex 4.2 Q1 (iii) • Board Exam Classic Irrational / Radical Coefficients
Solve by factorisation: √2x² + 7x + 5√2 = 0
Step 1: Compute Target Product a · c
a = √2, b = 7, c = 5√2. Product: a · c = (√2) × (5√2) = 5 × 2 = 10.
Step 2: Find Factors of 10 Adding to 7
Factors of 10: 5 and 2. Notice: 5 + 2 = 7 and 5 × 2 = 10. Perfect!
Step 3: Split the Middle Term & Group
√2x² + 5x + 2x + 5√2 = 0
Rewrite 2 as (√2 × √2):
x(√2x + 5) + √2(√2x + 5) = 0
Step 4: Factor Out Common Binomial & Equate to Zero
(√2x + 5)(x + √2) = 0
Case 1: √2x + 5 = 0 ⟹ x = -5/√2 (or -5√2/2)
Case 2: x + √2 = 0 ⟹ x = -√2
Roots are -√2 and -5/√2.
NCERT Ex 4.2 Q5 • Applied Pythagoras Right Triangle Altitude
The altitude of a right triangle is 7 cm less than its base. If the hypotenuse is 13 cm, find the other two sides.
Step 1: Set Up Variables with Pythagoras Theorem
Let base = x cm. Then altitude = (x - 7) cm. Hypotenuse = 13 cm.
Pythagoras theorem: base² + altitude² = hypotenuse² ⟹ x² + (x - 7)² = 13²
Step 2: Expand & Simplify to Standard Form
x² + (x² - 14x + 49) = 169
2x² - 14x + 49 - 169 = 0 ⟹ 2x² - 14x - 120 = 0
Divide by 2: x² - 7x - 60 = 0
Step 3: Factorise & Apply Real World Constraint
Factors of -60 adding to -7 are -12 and +5:
(x - 12)(x + 5) = 0 ⟹ x = 12 or x = -5.
Since physical side lengths cannot be negative, discard x = -5.
Therefore: Base = 12 cm, and Altitude = 12 - 7 = 5 cm! (Check: 5² + 12² = 25 + 144 = 169 = 13²).

Exercise 4.3 — Formula & Discriminant Analysis

श्रीधराचार्य द्विघाती सूत्र एवं विविक्तकर की प्रकृति
Class 10 NCERT 4.3
👑 Shreedharacharya's Quadratic Formula (द्विघाती सूत्र)
When an equation cannot be easily factored, the universal quadratic formula directly yields both roots for any ax² + bx + c = 0:
x = (-b ± √(b² - 4ac)) / (2a)
Discriminant D = b² - 4ac decides the nature of the roots!
Case 1: D > 0
Two distinct real roots (दो भिन्न वास्तविक मूल). Parabola cuts x-axis twice.
Case 2: D = 0
Two equal real roots (दो बराबर वास्तविक मूल, x = -b/2a). Parabola touches x-axis at vertex.
Case 3: D < 0
No real roots (कोई वास्तविक मूल नहीं). Parabola floats above/below the axis without touching it.
NCERT Ex 4.3 Q2 (i) • Board Question Condition for Equal Roots
Find the values of k for which 2x² + kx + 3 = 0 has two equal real roots.
Step 1: State the Equal Root Condition
For equal real roots, the discriminant must be exactly zero: D = b² - 4ac = 0.
Step 2: Identify Coefficients and Substitute
a = 2, b = k, c = 3.
D = k² - 4(2)(3) = k² - 24.
Step 3: Solve for k
k² - 24 = 0 ⟹ k² = 24
k = ±√24 = ±√(4 × 6) = ±2√6
Therefore, k = 2√6 or -2√6!
NCERT Ex 4.3 Q4 • Classic Work & Time Two Water Taps Filling a Tank
Two water taps together can fill a tank in 9⅜ hours (75/8 hours). The tap of larger diameter takes 10 hours less than the smaller one to fill the tank separately. Find the time in which each tap can separately fill the tank.
Step 1: Formulate Rates of Filling
Let smaller tap take x hours. Larger tap takes (x - 10) hours.
In 1 hour: smaller fills 1/x of tank; larger fills 1/(x - 10) of tank.
Together in 1 hour they fill: 1 / (75/8) = 8/75 of the tank.
Step 2: Build the Fractional Equation
1/x + 1/(x - 10) = 8/75
[(x - 10) + x] / [x(x - 10)] = 8/75 ⟹ (2x - 10) / (x² - 10x) = 8/75
Cross multiply: 75(2x - 10) = 8(x² - 10x) ⟹ 150x - 750 = 8x² - 80x
Standard Form: 8x² - 230x + 750 = 0 (Divide by 2: 4x² - 115x + 375 = 0)
Step 3: Solve by Factorisation
4 × 375 = 1500. Factors adding to -115 are -100 and -15:
4x² - 100x - 15x + 375 = 0 ⟹ 4x(x - 25) - 15(x - 25) = 0 ⟹ (x - 25)(4x - 15) = 0
Roots: x = 25 or x = 15/4 = 3.75 hours.
If x = 3.75, larger tap time x - 10 = -6.25 hours (impossible!). Discard x = 3.75.
Thus: Smaller tap takes 25 hours, and Larger tap takes 15 hours!
