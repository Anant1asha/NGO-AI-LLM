# NGO AI LLM Core Architecture

- **Project Root**: AASHA AI Learning Ecosystem (`NGO AI LLM`).
- **Core Purpose**: AI-powered adaptive multi-agent learning platform for K-12 interactive education, bilingual Hindi-English definitions, offline-capable HTML5 chapter modules, and telemetry-driven misconception diagnosis.
- **Default Local Memory**: Serena MCP is the designated default local memory engine (`.serena/memories/`), organizing persistent architectural rules, invariant conventions, and domain knowledge.
