# Conventions & Invariants

0. **Ecosystem Identity Invariant (Autonomous AI Agent System vs. Building LLM)**: Despite the nominal workspace directory name `NGO AI LLM` and remote repository URL `https://github.com/Anant1asha/NGO-AI-LLM.git`, this ecosystem **DOES NOT BUILD, PRE-TRAIN, OR FINE-TUNE LARGE LANGUAGE MODELS**. It is an **Autonomous AI Agent Ecosystem (AASHA AIOS)** implementing multi-agent orchestration (7 pipeline agents in `agents.json`), multi-tier memory (Serena MCP, Mem0, SQLite, AST graph), multi-tools & simulation engines (F01–F20, PyMuPDF, math insulator, CDP automation), curated resources, and procedural skills. External LLMs are consumed strictly as swappable reasoning engines via the 3-tier anti-bleed router (`packages/llm-router/openrouter_client.ts`).
1. **Zero-Token Bleed & Laya Pre-Router**: Never chain fallbacks into paid Gemini keys. Always route unclassified requests through Laya System 1 (`packages/llm-router/laya_classifier.ts`) locally to isolate Indic scripts in <1ms and classify task domains without spending API tokens.
2. **TypeScript Dual-Root Bundler Resolution**: Maintain synchronized `tsconfig.json` files at workspace root and package subroots specifying `"types": ["node"]` and `"moduleResolution": "bundler"`, preventing language server degradation into DOM-only mode and avoiding false `.js` extension errors in `tsx` projects.
3. **CanonicalIR Schema v1.1.0 Contract**: Enforce structured `chapter_metadata: { chapter_id, ... }`, `{ canonicalIR, validationErrors }` assembly returns, and static `V6Compiler.compile(ir)` calls.
4. **Mathematical Insulation**: Shield all LaTeX math (`\( ... \)`, `$$ ... $$`, `$...$`) and single-letter variables via `__AASHA_MATH_X__` before applying bilingual dictionary wrapping (`rt()` / `window.WM`).
5. **Symbolic Operations First**: In Serena, use AST/symbolic tools (`find_symbol`, `get_symbols_overview`, `replace_symbol_body`, `rename_symbol`) over raw line replacements whenever manipulating classes or methods.
6. **Zero-Spoiler Assessment**: Misconception diagnostics (`m`) and 4-tier progressive hints (`H1` to `H4`) must never leak answers or verbatim calculations evaluating to target values.
7. **Responsiveness & Physical Touch Ergonomics**: Concept cards and `<aasha-sim>` canvas viewports must fit within mobile viewports without vertical scroll (`scrollH <= winH + 5`). Minimum touch target 44x44px for every interactive element (buttons, tabs, sliders, tap cells) across standard viewports (360x640, 390x844, 412x915). High contrast styling must prevent text/background readability conflicts.
8. **Canonical Source Textbook Repository**: All source curriculum textbook PDFs reside at `Aasha-AI/content/pdfs/` (e.g. `AD class 8th math rational number.pdf`, `square and cube RL public school and ncert.pdf`). Both CLI (`aasha.cli --pdf`) and pipeline orchestrator auto-discovery (`_find_source_pdf`) automatically index and resolve from this directory.
9. **Automated Rule Validation & Zero-!!seq Invariant**: Whenever creating or modifying rules in `.agents/rules/*.md` or `.superbrain/rules/*.md`, strictly use `trigger: always_on` (or `trigger: model_decision`), non-empty `description`, and scalar string `globs: "**/*"`. Never author YAML sequence arrays (`globs: [...]`), which crash Antigravity's Go language server (`language_server.exe`) with `cannot unmarshal !!seq into string`. AUTOMATION TASK: Always run `npm run lint:superbrain` immediately after modifying rules to verify 100% schema compliance and cross-IDE parity.
10. **Multi-Modal Interactive Simulation Mandate**: Deliver dynamic, rich conceptual simulations beyond static or procedural SVGs. Use 60 FPS HTML5 Canvas particle convection, interactive chemical dropper assays with effervescence diffusion, mechanical torque lever physics, Mendelian gamete matrix segregation, and rotatable 3D blocks. All simulations must run 100% offline with zero CDN dependencies, staying well within the 20 MiB single-file ceiling.
11. **Autonomous Open-Source Harvesting & Quality Gate Pipeline**: Continually harvest, cleanroom-adapt, and admit high-production educational interactives from proven open-source repositories (PhET, KingsMath, JSXGraph, GeoGebra, Escapp, CinePhysicsHQ). Enforce the 5-Point Quality Gate: (1) Zero external network calls, (2) Local/inlined dependencies, (3) >=44px mobile touch ergonomics, (4) Same-frame responsive viewport clamping, (5) AASHA Experience Contract telemetry (`window.AASHA.emit`). Register all admitted assets in `assets/prestack_manifest.json` and `Aasha-AI/experience_registry/registry.json`.
12. **Multi-Layer Language Learning Experience (LLE) & Acharya Persona**: Provide seamless dual-layer bilingual scaffolding: (1) Word-level tap-to-reveal phonics, Hindi transliteration, and contextual meanings, (2) Sentence-level tap-to-reveal full Hindi translations. Voice and pedagogical explanations must embody an authentic, warm Indian mentor persona (like top YouTube educators from India) who connects naturally with students, strictly avoiding sterile AI jargon and never using informal Hinglish.
13. **Comprehensive Chapter Concept Coverage**: Never generate simplified toy summaries or cutdown placeholders. Every chapter module must comprehensively cover all syllabus concepts, worked steps, common misconceptions, and multi-tier gamified mastery challenges matching NCERT, CBSE, ICSE, and State Board standards.
