# /jagiye-maakiran: Serena Local Memory Wake-Up & System Priming

**॥ जागिए माँ किरण — Jagiye Maa Kiran ॥**

The master wake-up, health verification, and auto-activation command for the AASHA AIOS Learning Platform.

## Purpose

When Antigravity opens in an arbitrary folder, upon PC startup, or whenever Serena MCP starts without an active project, `/jagiye-maakiran` guarantees 100% self-healing activation and semantic memory priming.

## Execution Sequence

```
1. SERENA MCP PROBE ➔ 2. ACTIVATE 'NGO AI LLM' ➔ 3. VERIFY 7/7 MEMORIES ➔ 4. AUDIT GRAPHIFY AST ➔ 5. REPORT DASHBOARD
```

1. **Activate Project**:
   ```json
   call_mcp_tool: {
     "ServerName": "serena",
     "ToolName": "activate_project",
     "Arguments": { "project": "NGO AI LLM" }
   }
   ```
2. **Verify 7 Core Memories**:
   - `mem:core`
   - `mem:local_memory`
   - `mem:tech_stack`
   - `mem:suggested_commands`
   - `mem:conventions`
   - `mem:task_completion`
   - `mem:memory_maintenance`
3. **Local AST Knowledge Verification**:
   - Verifies `graphify-out/graph.json` contains active codebase symbols.
4. **Offline Dual-Plane Verification**:
   - Confirms zero-cost local episodic memory in `.scratch/mem0_store.json`.
5. **Output Dashboard**:
   - Displays the formatted status badge and reports operational readiness.
